## Spec (агент, дослівно; перевірено пробами на копії `tests/fixtures/scapi`)

Right for `dw.ocapi.*` and `dw.order.calculate`, wrong for `app.payment.processor.BASIC_CREDIT` (script exports `Handle`/`Authorize`) and `app.payment.form.processor.*` (`processForm`). Probe: such a hook now yields **no entry at all** (before: every export).
2. **"An API it knows" is a naming convention, never checked against the shipped table.** Spec: "names an operation of an API it knows" (analysis). `src/apis.ts:46-72` accepts any `shopper[A-Z]…` receiver / `Shopper[A-Z]…` type for any gap but `parse-error`/`local` (`src/graph.ts:847`); `SCAPI_TABLE`/runtime table is not consulted. 3. **`reduce` misattributes the accumulator as a field of the result.** Spec: reads "through the first parameter of a callback an array of it is iterated with". `src/extract/ts.ts:1029` includes `reduce`, whose first parameter is the accumulator. ## Design (агент; перевірено: відсутність читачів полів фактів, викидання kind-ів сторінкою)

### 1. Вид реєструється один раз — **Strong**
**Файли:** `src/view-keys.ts`, `src/views.ts` (viewList 144–208, viewOf 914–998), `src/picture.ts` (readAtTheEdge), `src/markdown.ts`, `src/export/mermaid.ts`, `src/options.ts` (MERMAID_ONLY_FOR), `src/routes/pictures.ts` (TAG_OF_KIND), `src/cli.ts`, `web/src/views-list.ts` (GROUPS), `web/src/link.ts` (OVERVIEWS), `web/src/navigation.ts`, `web/src/export-menu.ts`.
**Проблема:** один концепт, дванадцять ручних таблиць; коміт `postman` правив сім лише для реєстрації, `apis` — дев'ять; ніщо їх не звіряє. **Перевірено:** сторінка рендерить лише kind-и з `GROUPS` — `logic`, кожен `logic:<fn>`, `intent`, `modules`, `branches` сервер віддає, список мовчки викидає; `markdown.ts:149` читає ключ `startsWith("apis")` руками (проти ADR 0004).
**Рішення:** `VIEW_KINDS` (уже Node-free шов, який бандлить сторінка) описує kind цілком (питання, група, порядок в огляді, шаблон крихт, тег, Mermaid-типи); `viewOf`/`viewList`/`readAtTheEdge` диспетчеризуються через один record на kind; GROUPS/OVERVIEWS/TAG_OF_KIND стають похідними; unit-тест обходить таблицю.
**Виграш:** locality — одне місце на вид; незареєстрований kind не проходить typecheck; CLI і сторінка не можуть розійтися.

**Стало.** `KindSpec` описує kind цілком: `overview` (підпис у пікері оглядів), `group` (група списку сторінки для видів із предметом), `tag` (префікс чат-тега і що він каже), `crumbs` (шаблон крихт: `layer`, `dir`, `classes`, `code`, `type`, `under`, `kind`), `mermaid` (типи Mermaid, які читаються краще), `form` (синтаксис предмета для `--help`); `subjects` став записом предмет → підпис (`cycles:fns` → "call cycles"). Похідні: `overviews()` → `OVERVIEWS` пікера, `listGroup`/`listGroups` → групи списку (`GROUPS` видалено), `tagOf` → теги чату (`TAG_OF_KIND` видалено), `crumbTemplate` → крихти без списків kind-ів, `mermaidTypesOf` → меню експорту, `viewSyntax()` → рядок видів у `--help`; `MERMAID_ONLY_FOR.kinds` типізовано `ViewKind[]`, правило gitGraph у `mermaidStyleFor` читає його замість ключа. Сторінка більше не губить `logic:<fn>`, `intent`, `modules`, `branches`; пікер знає `postman`. Залишено як є: `viewOf` (один вичерпний `switch`, незареєстрований kind не компілюється), `viewList` (порядок — порядок сервера) і `readAtTheEdge` (шість kind-ів, що читають git). Видимі зміни: порядок груп списку — порядок таблиці; голі `apis`/`postman` — серед оглядів. Юніт-тест обходить таблицю і списки фікстур sample/scapi/machines: кожен вид сервера має групу.

### 2. Факти, яких ніхто не читає (deletion test) — **Strong**
**Файли:** `src/extract/facts.ts`, `src/extract/ts.ts` (decorators 1895–1980, hooks/defaults 2556–2702, routes/web/pages 3208–3528), `python.ts`, `php.ts`, `src/cache.ts:24–31`.
**Проблема:** сімейство фактів пишеться «для адаптера фреймворку», якого в archdiff немає. **Перевірено grep-ом:** `web`, `statements`, `paramCalls`, `decorators`, `readsImports`, `traitRules`, `attributes`, `docblock`, `closureArg`, `closures` не мають жодного читача поза `src/extract/`; ≈550 рядків ts.ts і ≈250 facts.ts у кожному facts.json.gz, а `EXTRACTOR_VERSION` хешує їхні джерела — кожна правка мертвого коду інвалідовує всі кеші. (`hook`, `param`, `args`, `chain`, `literal` читачів мають — перевіряти поле за полем перед видаленням.)
**Рішення:** видалити писачів і типи без читача; залишити `nameArg`, `guards`, `passes`, `instances`, `shape`/`reads`/`returnsFrom`, `properties`/`fields`, `result`, `traits`/`base`/`implements`, `symbols`.
**Виграш:** інтерфейс фронтенду звужується до того, що читають граф і види; менші кеші, менше інвалідацій; ts.ts втрачає третину поверхні ще до розділення; доводиться побайтово на фікстурах.

**Стало.** Видалено записувачів і типи без читача: у `ts.ts` — декоратори (`decoratorsOf`, `parameterDecorators`, `decoratorFact`, `decoratorArg`), хуки з умовчаннями (`localHook`, `fallbackOf`, `defaultIn`, `ClassScope.hooks/params`), маршрути, web-реєстрації й сторінки (`collectRouteEntries`, `collectWebFacts`, `lazyImports`, `pageOf`), `markClosure`, `readsImports`, `literal`; у `python.ts` — `statementsOf`, `noteParamCalls`, `collectMainEntries`, `bindsUnlisted`, `literalOf`/`argumentsOf`, стан замикань; у `rust.ts` — стан замикань; у `php.ts` — `interfaceMethods`, правила трейтів (класи, які вони називають, лишаються залежностями), `attributesOf`, `chainOf`, `argsOf`/`argList`, параметри й `returns` fn, стан замикань у `callsIn`, `args` у `ValueOfFact` (знайдено на додачу до десяти полів ревю). `facts.ts` втратив 15 типів; `PropertyFact.value` лишено: `informative(literalOf(...))` вирішує, які властивості показує `classes`, тож це зміна поведінки для окремого рішення. Разом −1 512 рядків. Доказ: `edges-of`/`logic-of`/`views-of` (хеш кожного виду) на fixtures, tabhelm, archdiff, keylang і storefront — побайтово однаково з HEAD; кеш фактів інвалідується сам (версія — хеш джерел `src/extract/`).

### 3. Postman/SCAPI: один концепт у п'яти модулях і виді — **Strong**
**Файли:** `src/apis.ts`, `src/scapi-runtime.ts`, `src/scapi-table.ts`, `src/contracts.ts`, `src/postman.ts`, `src/collections.ts`, `src/views-more.ts:1180–1288`, `src/analyze.ts:137–138`, `src/cli.ts:426`, `src/routes/pictures.ts:260`.
**Проблема:** форма таблиці відома в трьох місцях (`postman.ts:70` рахує `${basePath}${path}` поруч із `operationPath`); тип `Route` і цикл найкращого збігу — у виді, а граматики wildcard — у collections.ts; regex-читач d.ts постачальника — в «чистому» apis.ts, що змусило стрілку scripts → core; ім'я колекції складають два викликачі; `readCollections` виконується на кожному аналізі кожної ревізії без мемо.
**Рішення:** два модулі — runtime (тип, вбудована таблиця, читач d.ts і node_modules, `operationPath`) і collection (write з контрактів, read у запити, match до операцій, ім'я) — вид питає лише «які запити збігаються з якими операціями»; колекції, можливо, читати на краю (`EdgeReads`, як `logic`).
**Виграш:** збіг тестується без репозиторію; одна нотація маршрутів; вид — лише малювальник.

### 4. ts.ts: два обходи scope, три турботи — **Worth exploring**
**Файли:** `src/extract/ts.ts` (declarationOf 2477–2530, bindingOf 2942–2985; values 924–1313; routes/web 3201–3528).
**Проблема:** `bindingOf` і `declarationOf` — один і той самий обхід (функції, блоки, `for…in`, `for`, `catch`, іменовані функціональні вирази), написаний двічі; 3 578 рядків тримають мову, потік значень (сьогоднішні 390 рядків) і словник фреймворків за одним глибоким інтерфейсом `extractTs`.
**Рішення:** один пошук scope (`bindingOf` як похідна від `declarationOf`); після №2 — розділити за турботами в `extract/ts/` зі спільним `Extraction`. Інтерфейс не рухається.

**Рекомендація агента (поділяю):** спершу №2 (видалення без зміни поведінки, доводиться побайтово, зменшує кеш і те, що ділитиме №4), потім №1 (три з чотирьох останніх фіч були нові види, кожна заплатила «податок дванадцяти місць», а сторінка вже мовчки губить kind-и), №3 — поки код Postman свіжий.

### Нотатки (не кандидати)
