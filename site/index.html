How to install

archdiff itself

The extensions draw nothing themselves: they show what the archdiff of your repository draws. It is an npm package (Node 22.18 or newer):

npm install -g @ivlad003/archdiff
archdiff web

Chrome extension

  1. Unpack the .zip into a folder that stays where it is.
  2. Open chrome://extensions and turn on Developer mode (top right).
  3. Press Load unpacked and pick that folder.
  4. Start archdiff web in your checkout, open the repository on GitHub and press the extension's button.

To update: unpack the newer build over the same folder and press the reload arrow on the extension's card.

VS Code extension

In VS Code: the Extensions view, its … menu, Install from VSIX…, and pick the file. Or from a terminal:

code --install-extension archdiff-vscode-0.1.0.vsix
